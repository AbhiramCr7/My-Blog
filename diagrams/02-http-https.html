Plain HTTP vs HTTPS

HTTP — port 80 The request is just text on the wire.

GET /login HTTP/1.1
Host: shop.test

Anyone on the path can read it.
Burp can read it with no extra work.
HTTPS — port 443 TLS wraps that same HTTP in a lock.

Browser and server share keys.
Outsiders see only ciphertext.

Burp must break TLS, read the HTTP,
then lock it again toward the server.

HTTPS does not change the HTTP message. It only hides it. Burp’s job is to unhide it for you, then hide it again.
